# 水果忍者 · 果切道场

一个无需安装的 HTML 水果切割小游戏，由GPT-6 Astra制作，支持电脑鼠标和手机触控。

## 玩法

- 按住鼠标拖动，或用手指滑动切水果。
- 经典模式：60 秒内挑战高分，切中炸弹扣 10 分。
- 生存模式：漏掉 3 颗水果或切中炸弹，游戏结束。
- 禅模式：90 秒自由切水果，没有炸弹。
- 同一笔连续切到 3 颗及以上水果可获得额外连击分数。
- 支持音效开关、暂停、全屏及本机最高分记录。

## 本地运行

用浏览器打开 `index.html` 即可，无需安装依赖或联网。

## GitHub Pages

在仓库的 **Settings → Pages** 中，选择 **Deploy from a branch**，分支选 **main**，目录选 **/(root)**，保存并等待部署完成。

全部游戏代码、图形和音效都包含在 `index.html` 中。
